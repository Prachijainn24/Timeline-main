# ACM Student Chapter — Timeline Website

This project was created for the ACM Student Chapter at Banasthali Vidyapith.

The website showcases the chapter's events, activities, milestones, and memorable moments through an interactive timeline.

## Getting Started

This project was created using React and Vite.

### Prerequisites

Make sure you have Node.js and npm installed on your system.

## Installation

In the project directory, you can run:

```bash
npm install
```

Installs all the required dependencies.

## Available Scripts

### `npm run dev`

Runs the app in development mode.

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

The page will reload automatically when you make changes.

### `npm run build`

Builds the app for production.

```bash
npm run build
```

The production-ready files will be generated in the `dist` folder.

### `npm run preview`

Previews the production build locally.

```bash
npm run preview
```
